# 🎬 Netflix UI Clone

This is a **frontend-only clone** of the **Netflix landing page**, built purely using **HTML** and **CSS**. The project replicates the look and feel of Netflix’s homepage, including sections like the hero banner, navigation bar, feature highlights, and footer.

---

## ✨ Features

- ✅ Fully responsive layout
- 🎨 Modern Netflix-inspired design
- 🌐 Navbar with logo, sign-in button, and background image
- 📦 Organized HTML structure and reusable CSS classes

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
